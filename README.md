# File-System-BFS-DFS-


File System Representation and Search Using BFS and DFS in C
## Objectives
- Represent files and directories as graph nodes.
- Implement BFS and DFS algorithms.
- Search for a specified file.

## Technologies Used
- C Programming
- Graph
- Adjacency Matrix

## Files Included
- filesystem.c
- input.txt
- output.txt

## Conclusion
This project demonstrates file searching using BFS and DFS algorithms.
